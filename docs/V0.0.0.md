# ProdKit Workflows v0.0.0

Initial organization workflow control plane.

This release establishes reusable CI and Security matrices, exact-SHA guarded GitHub Releases, immutable tags, SPDX SBOM generation, provenance attestations, draft-first checksum-verified publication, consumer bootstrap contracts, importable organization rulesets, and organization-wide workflow drift auditing.

The final v0.0.0 contract is GitHub-hosted-first with explicit trusted self-hosted failover. CI and Security adapter paths are runtime-contained beneath `.prodkit/workflows/`; full-history Gitleaks produces redacted evidence and supports repository-contained reviewed allowlists; release-manifest v1 is strictly shape-validated; and consumer release output is rejected if it is empty, nested, symlinked, or attempts to overwrite central proof/source/SBOM artifacts. Contract tests lock these guarantees to `docs/CONTRACTS.md`, bootstrap output, local validators, and reusable workflow behavior.

The workflow surface is intentionally layered rather than one-to-one: `.github/workflows/` contains 8 YAML files (4 operator-facing workflows plus 4 reusable implementations), the generated consumer adapter catalog contains 11 shell adapters, and this control-plane repository itself enables only 4 `.prodkit/workflows/` adapters. Disabled capabilities do not require local adapter files; enabling a capability makes its configured adapter mandatory and runtime-validated.
